PROJECT 01 / MOBILEIn development

Odyssey

Wellness and productivity app.

Combines mood tracking, habits, journaling, and a focus timer. An experience, level, and achievement system is tied to in-app activities.

FlutterDartRiverpodSupabaseFirebase
Project details +

The challenge

Bring personal records and daily planning tools into a consistent experience, including offline use.

Technical decisions

Flutter for the interface, Riverpod for state management, Hive for local storage, and Supabase for cloud data. A feature-based structure separates the interface, models, and persistence.

Implementation

An offline queue for mood records, with model and form tests. The app is in development.
